# Practice 5: Python Regular Expressions (RegEx)

## Files

| File | Description |
|------|-------------|
| `regex_examples.py` | RegEx examples: search, findall, split, sub, match, metacharacters, special sequences, quantifiers, flags, regex.md exercises |
| `receipt_parser.py` | Parses `raw.txt` pharmacy receipt — extracts prices, product names, total, date/time, payment method, outputs JSON |
| `raw.txt` | Source receipt (EUROPHARMA Астана) |
| `receipt_parsed.json` | Auto-generated structured output |

## Run

```bash
python3 regex_examples.py
python3 receipt_parser.py
```
