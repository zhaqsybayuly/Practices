# Practice 4 — Python Advanced Topics

Solutions for the four exercise sets in the [exercices](./exercices/) folder.

## Files

- `generators.py` — iterator and generator exercises (5 tasks)
- `dates.py` — datetime and timedelta exercises (4 tasks)
- `math.py` — math module exercises (4 tasks: degree→radian, trapezoid, regular polygon, parallelogram)
- `json.py` — parses `exercices/json/sample-data.json` and prints an interface status table

## Run

```bash
python generators.py
python dates.py
python math.py
python json.py
```
