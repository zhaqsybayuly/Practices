# Practice 3: Python Functions and Object-Oriented Programming

This project is intended to compile practical assignments for the Programming Principles 2 course.

This project covers Python functions, lambda expressions, classes, objects, and inheritance.

## Project Structure

```text

├── functions/

├── lambda/
```

## Topics Covered

1. **Functions**: Definitions, various argument types (*args, **kwargs), return values, and docstrings.
2. **Lambda Expressions**: Syntax and usage with `map()`, `filter()`, and `sorted()`.
3. **Classes and Objects**: Constructors (`__init__`), instance methods, and class vs instance variables.
4. **Inheritance**: Parent/child relationships, `super()` calls, method overriding, and multiple inheritance.
