# Paint

Simple drawing app with pygame.

## Tools (top-left buttons)
- **pen** — freehand drawing
- **rect** — drag to draw a rectangle
- **circle** — drag to draw a circle
- **eraser** — drag to erase (white, thicker)

## Color palette (top-right)
Click a color square to select the active color. The selected color gets a thicker border.

## Run
```bash
python main.py
```
