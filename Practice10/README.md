# Practice 10 — Pygame Games

Three pygame projects:

1. **racer/** — top-down racing game with coins
2. **snake/** — snake game with levels and increasing speed
3. **paint/** — drawing app with pen, shapes, eraser and color palette

## Setup
```bash
# use the Practice9 venv (it already has pygame)
source ../Practice9/venv/bin/activate
# or make a fresh one:
# python3.13 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
```

## Run
```bash
cd racer && python main.py
cd ../snake && python main.py
cd ../paint && python main.py
```
