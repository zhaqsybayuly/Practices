# TSIS2 — Paint Extended

Extends Practice 10-11 paint with:
- **pencil** (freehand) and **line** (click-drag) tools
- **3 brush sizes** (S/M/L) — switchable via toolbar buttons or keys 1/2/3
- **flood fill** (BFS pixel fill)
- **Ctrl+S** → save canvas as `canvas_YYYYMMDD_HHMMSS.png`
- **text tool** — click on canvas, type, Enter to confirm, Escape to cancel
- All Practice 10-11 shapes still respect the active brush size

## Run
```bash
python paint.py
```
